# 🚀 SKILLGRAPH

### **Your career is not a résumé. It's a continuously changing skill graph.**

**Tag:** `#commercial-potential`
**Lane:** `#startup`

We will build a platform that answers one fundamental question:

> **"Given what I can actually prove today and what the market is asking for, what should I do next?"**

> "What career should I choose?"

**Do not open VS Code and tell the coding agent to build SkillGraph yet.**

First we need to create the **SkillGraph Master Specification v1**.

That specification will become the single source of truth for the coding agent and will prevent exactly the hallucination/chaos problem you had with your previous Java project.

The first agent instruction will eventually look like:

> **"You are working on SkillGraph. Do not invent requirements. Read `/docs/product-spec.md`, `/docs/architecture.md`, and `/docs/agent-rules.md` before modifying the codebase.
