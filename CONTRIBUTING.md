# Contributing to SkillGraph

Thank you for your interest in contributing to SkillGraph!

## Development Guidelines

All contributors and AI coding agents must strictly adhere to:
1. [`docs/product-spec.md`](docs/product-spec.md): Product scope boundaries and MVP guidelines.
2. [`docs/architecture.md`](docs/architecture.md): Approved AWS cloud patterns and data flows.
3. [`docs/agent-rules.md`](docs/agent-rules.md): Inviolable operating invariants and the 7-step development loop.
4. [`docs/agent-log.md`](docs/agent-log.md): Mandatory logging for all tasks and architectural touches.

## Pull Request Process

1. Ensure all code changes have corresponding unit tests.
2. Verify that no new unapproved AWS services or third-party dependencies are introduced.
3. Run linting, type-checking, and test suites locally before submitting.
